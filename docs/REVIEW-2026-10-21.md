# 추가 안정성·성능 검토 (2026-10-21)

이 문서는 기존 Win10 21H2 가상 머신 검증 이후의 추가 변경만 기록한다.

## 수정한 문제

- Capture/Renderer의 DXGI 어댑터·출력 열거에서 NOT_FOUND 외 오류와 빈 COM 객체를 검사하지 않아 역참조가 발생할 수 있었다. 실패 시 오류를 기록하고 정상적인 실패 경로로 반환하도록 수정했다. 캡처 측 어댑터 설명 조회 실패도 반환한다.
- 커서 이미지 변환에서 전체 버퍼 크기만 검사해 한 행의 Width에 비해 작은 Pitch가 허용됐다. 컬러/마스크 컬러 행 크기, 단색 AND/XOR 두 마스크의 짝수 높이, 정수 오버플로 및 출력 컨테이너 한계를 검사한다. 재사용 버퍼 전체 길이 대신 GetFramePointerShape가 반환한 실제 데이터 길이를 span으로 전달한다.
- 드라이버 연결 중 취소됐어도 정상 연결이 반환될 수 있었다. 열기 및 상태 핸드셰이크 직후 취소를 검사하고 핸들을 정리한다. 변경 IOCTL 호출 직전에도 취소를 검사한다. 이미 OS에 전달된 동기 IOCTL을 중단한다고 보장하지 않는다.
- 상태 읽기에서 취소 예외가 오류 문자열로 바뀌던 경로를 수정했다.

## 최적화

- 프레임마다 생성하던 Snapshot vector를 기존의 1~4칸 라우팅 한도에 맞는 stack array로 변경했다. 프레임당 해당 컨테이너의 힙 할당/해제를 제거한다. InitDevice의 기존 한도 검증을 유지한다.
- 커서 변환 출력은 모든 픽셀을 덮어쓰므로 매번 0으로 채우던 assign 대신 resize로 저장 공간을 재사용한다. 커서 형태 변경이 없을 때 텍스처를 갱신하지 않는 기존 경로는 유지한다.

## 검증

- .NET Release 빌드: 경고 0, 오류 0.
- C++20 합성기 Release 빌드 성공. 합성기 자체는 호스트에서 실행하지 않았다.
- 새 PointerProbe: 패딩 있는 컬러, AND/XOR, 마스크 컬러, 저장 공간 재사용, 잘린 데이터/짧은 Pitch/홀수 높이/오버플로/알 수 없는 형태 등 15개 검사 통과. 디스플레이 API 활성화 없음. CI에도 추가했다.
- ui-smoke의 win10-fixes/matrix/refactor/stability/live-sync/shortcuts 6개 시나리오 통과. 새 취소 회귀 검사는 가짜 장치만 사용한다.
- 기존 로그 합성 벤치마크도 실행했지만 이는 로그 처리 지표이며 화면 전환/FPS 개선 수치로 해석하지 않는다.

## 남은 실측 항목

- 실제 GPU에서 새 합성기의 GPU 재시작/도킹 변화 및 커서 표시 검증.
- 서로 다른 GPU 사이 CPU staging 복사 비용과 1ms idle capture polling의 CPU 부하. 타이머를 임의로 늘리면 입력 지연이 커질 수 있어 이번에는 변경하지 않았다.
- 창 복원은 비동기 배치 요청이므로, 대상 앱이 요청을 처리한 시점까지 보장하지 않는다. 실제 앱 조합별 전환·복원 지연 측정이 필요하다.
- 이번 변경 이후 Win10 VM 전체 재검증은 수행하지 않았다. 기존 0.5.6-Win10DriverFix 설치 파일과 25개 VM 검사 기록은 이전에 검증한 바이트 그대로 보존했다.
- 후속 요청으로 최신 앱·합성기와 검증된 v2 드라이버를 묶은 DesktopSplitter-0.5.6-StabilityFix-win-x64-Setup.exe를 생성했다. SHA256: A4F6352DE4DE41B3D747DD8AF2143D6F24B90C78A56658A1F1F4DFEED3365ACA. 동봉 10개 파일의 해시, INF 검사, 자체 검사가 통과했다.
- 호스트 Windows 11에서 해당 설치 파일로 업데이트했다(종료 코드 0). pnputil에서 oem8.inf / 0.38.43.62 / Started를 확인했고, 설치된 DLL 및 앱·합성기의 해시가 payload와 일치한다. 일반 권한 앱도 GET_STATUS v2 / 활성 가상 모니터 0개로 연결했다. 어댑터 상태 Ready(2), NTSTATUS 0. 호스트에서는 분할 적용·복원이나 디스플레이 배치를 변경하지 않았다. 설치된 앱을 --manual-review로 실행했다. 로그: artifacts/installer/host-update/.
